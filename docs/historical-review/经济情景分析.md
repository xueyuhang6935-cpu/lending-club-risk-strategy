## 假设现金流模型

为在数据不足时给出可复现的敏感性范围，仅采用明确假设的共同期限一次性现金流：每笔在t=0支出金额代理P及一次性成本fP；最终结清贷款在t=T收回P(1+y)^T，最终核销贷款在t=T收回ρP，不另加利息；按年折现率c折现。y是**假设的结清贷款年收益率**，不是实测合同利率；c代表假设资金时间成本，未另重复扣资金成本；ρ是相对于原P的假设总回收比例。两类均使用共同假设T，未模拟真实摊还和提前结清。

单笔NPV = [结清: P(1+y)^T；核销: ρP]/(1+c)^T − P(1+f)。本金已通过支出/收回计入，不再额外扣减核销本金。原核销仅用于假设的现金流分类。

共同保留部分用同一现金流假设，比较时抵消。令ΔG为换入减换出的结清贷款金额代理，ΔB为换入减换出的核销贷款金额代理，ΔP=ΔG+ΔB：

`ΔNPV = [ΔG(1+y)^T + ρΔB]/(1+c)^T − (1+f)ΔP`。

2014年ΔG=26,321,975，ΔB=−4,774,475；2015年ΔG=50,765,200，ΔB=−7,755,925。逐组金额见economic_exchange_2014/2015.json。

事先在计算代码固定网格：y∈{0,4%,8%}，c∈{0,4%,8%}，T∈{1,3}年，ρ∈{0,20%,40%}，f∈{0,1%}。每年108个情景，共216个；未从网格中选择“推荐”情景，不为这些假设赋概率。

| 年份 | ΔNPV代理单位最小值 | 最大值 |
|---|---:|---:|
| 2014 | −2,383,795.47 | +11,610,607.77 |
| 2015 | −5,603,076.60 | +20,940,256.62 |

范围跨零，说明仅凭笔数风险改善无法判断收入、成本和资金占用后的收益。这些数值不是实测收益、置信区间、预测范围或上线收益。

盈亏平衡回收率 `ρ* = [(1+f)ΔP(1+c)^T − ΔG(1+y)^T]/ΔB`（ΔB≠0），文件economic_break_even_2014/2015.csv报告是否位于[0,1]以及斜率。此处ΔB<0，其他假设固定时ΔNPV随ρ递减，故正收益条件为ρ<ρ*；根在[0,1]外时不能声称存在可行区间内的盈亏平衡点。

## 实际经济评价的缺口

| 需要补齐 | 用途 |
|---|---|
| 实际放款额、日期和逐笔期限/利率 | 确认资金流出和合同口径 |
| 核销时剩余本金与事件日期 | 区分原本金、余额、会计核销 |
| 每期本金、利息、提前结清及日期 | 重建真实资金占用与收益 |
| 回收、催收、服务费用及日期 | 净现金流，不重复核销扣款 |
| 适用资金成本、预算及再投资规则 | 同时间与同预算比较 |

取得这些数据后需另建真实现金流版本。当前只完成计划允许的数据不足情景分析分支；真实金额损失和实际净收益均为空，不以假设补成实测。
