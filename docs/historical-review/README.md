# 历史研究收尾与数据缺口

更新：2026-10-30。本项目按有边界的历史研究交付；当前无法开展向原作者索取数据及取得合格后续批次的路径，独立验证和实际收益评估暂不执行。未来若取得数据，再另立研究版本，不把当前历史结果转称独立证据。

## 核验结果

2026-10-29本地增量核验六个历史验收包151个文件，对891,702笔2014—2016已研究决策重新排序、核对同分规则、保留计数与核销数。生成阶段362项检查、最终548项检查通过；5项数据准入边界测试通过。这里发布汇总表，不上传逐笔贷款或个人简历。历史源文件和大型本地验收包未放入此仓库，完整原件哈希不能在此仓库单独复验；仓库原有核心结果仍可按根README从公开CSV重现。

2015年S0/S1各保留300,434笔，核销数56,252/54,751，差1,501笔；核销率差(54,751−56,252)/300,434×100=−0.499610563385个百分点。这是已获贷终态研究样本的离线比较，既不是实际避免的核销，也不是申请审批效果。

## 数据限制覆盖早期年份

[sample_flow_by_year.csv](sample_flow_by_year.csv)来自已发布年度×期限×状态汇总：2014、2015、2016年完整批次分别仍有12,527、45,550、141,312笔非终态贷款。因此早期年份也有终态选择限制。正式研究样本与终态总数少量差异的逐笔原因未全部恢复，不虚构排除原因。

旧上游版本对照曾发现829,347笔训练贷款中179,533笔，在较早版本仍未呈现最终结清/核销，新版本才有终态。该对照本身不能恢复2015年底的标签可用日；删去这部分亦不能证明其余标签当时已知。较早版本约为2018年上传，上传日不作为观察日。

2017/2018仅查过状态汇总与适用性，不曾构成合格独立效果评价。后续结果发生日、记录可用日、统一快照日、完整批次及观察充分性均需证实。贷款ID不等于借款人ID，现有资料无法排除跨集合借款人相关性。

## 经济评价

[经济情景分析](经济情景分析.md)与[金额代理对比](amount_proxy_comparison.csv)只使用旧开发字段loan_amnt，不能等同核实后的实际放款额、核销余额或损失。2015年S1同量保留金额代理更大。216个明确假设的现金流情景，其净现值差范围跨零，未证实真实收益；未将1,501笔差异换算为节省本金。

## 后续准入

`python audit/admission.py docs/historical-review/current_admission_request.json` 当前应退出2（不准入）。工具拒绝未知、缺失证据或哈希不符，只检查元数据完整性；自动通过仍需内容复核，不会直接开启评分，也不等于验证完成。测试：`python -m unittest discover -s audit -p 'test_admission.py' -v`。

合格新批次至少应具有同平台、完整贷款集合、贷前特征、可靠状态截至日、结果发生和记录可用日期、充分观察及未参与选优的证据。训练信息必须先于评价确实可用；若改变模型或标签，需要新的开发版本和另外的独立数据。真实经济评价另需实际本金、逐期还本付息、回收、费用和现金流日期。
