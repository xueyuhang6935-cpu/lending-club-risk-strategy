# 待办与限制

S1仅作后续验证候选，暂无合格独立样本，不宣布上线替换。2016已查看，2017/2018仅有历史状态适用性核查，未做策略效果评价。

缺统一快照、结果日期、可靠借款人键与历史标签可用日期；样本仅为已放款且已终结贷款，不能推广全部申请人或作利润估计。bootstrap不控制借款人相关性，不覆盖模型训练、选优、成熟度或未来环境风险。

收入增强S2开发期方向不一致，不采用；DTI混合口径与999、experience_c构造未通过。LightGBM、复杂特征、S3、校准和新实验均不在本版范围。

监控为拟议方案，尚未真实部署、指派人员或标定告警阈值。MySQL方言尚未实机验证，当前SQL只声明SQLite通过。
