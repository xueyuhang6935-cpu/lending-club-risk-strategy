# 监控与处置方案

生成时间：2026-10-24T21:39:58+08:00。性质：后续可执行的拟议监控安排，未上线、未接入实际申请流、未标定红黄灯阈值，也未验证业务收益。频率为本轮提出的工作约定，不是观测结果。

## 范围与责任

当前仅支持历史已放款且已终结样本的回溯与模拟。未来若用于实际流量，须先核查输入字段、贷前时点、模型、适用样本及完整阈值版本，并另经业务批准；本交付不执行部署。以批次输入为分母的即时指标可无结果观察，核销表现等须等待成熟并通过可比性准入。

拟议责任分工：数据负责人核对字段和来源；模型负责人复核评分、预处理和版本；策略分析负责人维护共同样本、分母和交换结果；业务评审人决定后续研究/暂停。当前未指派真实人员，运行前须落实责任与复核人。

## 执行步骤

1. 每批登记数据来源、截至日、输入覆盖、模型/预处理/阈值/分组版本与批次记录数；确认必要字段、标记和键完整。
2. 运行M01—M06即时检查，按批次保留分子、分母及输出；月度汇总不跨版本拼接。关键字段违反冻结输入约束时，暂停该批评分，先核实，不临时改阈值或补值。
3. 月度/季度评审M07，建立完整批次×期限×状态表和观察截至日记录。缺关键证据时标注不合格，不能继续解释为独立验证。
4. 仅在结果充分观察且准入通过后开展M08—M10；分年列示，对固定阈值与等量选择分别计算，空组或无定义指标保留NULL及原因。
5. 记录异常线索、检查证据、影响范围、处理建议、评审结论和复核结果。未建立数值基线前由人工复核线索，不将任意变化自动判成告警；版本错误或既有输入约束失败则按数据质量故障处理。

完整10项指标、分母、条件、拟议频率和处置见[监控指标字典](监控指标字典.csv)。[监控复核记录模板](监控复核记录模板.csv)只含表头，尚无实际运行记录。

## 排查顺序

先查字段缺失、未知类别、口径及来源，再查预处理/模型/阈值版本、评分分布和客群迁移；不得跳过数据检查直接解释为风险恶化。排序稳定但概率偏差扩大时，复核概率含义、样本成熟度及固定阈值适用性；校准需另设拟合与独立评价，严格单调校准不能预设等量收益。换入表现持续不利时，复核共同样本、交换数和差值，不以平均改善掩盖不利年份。

## 基线及阈值管理

现有W1模型2014→2015的S1开发结果可作历史参照：2015实际保留比例80.3136%，保留核销比例18.3540%。这是历史终态样本，不是线上预警阈值，也不能直接拿其他年份重训模型的概率诊断当固定W1漂移基线。

运行前积累同口径、同版本且可比的参考批次，由评审人冻结指标范围、最小数据条件、频率与告警判据。现阶段所有数值告警阈值均为“待建立”，不以本轮结果事后挑选业务价值门槛。不记录真实利润、避免损失或上线因果收益。
